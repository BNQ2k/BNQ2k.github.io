Ohjelmistotestauksen tehtävät

Raportit:
Robot Report | Robot Log

Tehtävä 1: Asennukset

Asennettu Robot Framework ja tarvittavat kirjastot:

pip install robotframework robotframework-browser robotframework-requests robotframework-cryptolibrary rfbrowser init

Tehtävät 2-4: Selaintestaus

Tehty perus kirjautumistesti (browser_demo.robot), Web form -testi (tehtava3.robot) ja päiväkirjamerkinnän lisäys (tehtava4.robot).

Tehtävät 5-6: Turvallisuus

Toteutettu kirjautuminen käyttämällä .env-tiedostoa. Tehtävässä 6 otettu käyttöön CryptoLibrary, jolla salasana on suojattu.

Tehtävät 7-8: Raportointi ja Github

Testitulokset on ohjattu omaan outputs-kansioon ja julkaistu tätä kautta github.io-sivuna.

robot -d outputs tests/front/

Tehtävä 9: API-testaus

Testattu backendin toimintaa localhost:3000 osoitteessa RequestsLibraryn avulla.

  • Tarkistettu että etusivu vastaa 200 OK.
  • Testattu että /api/users reitti palauttaa 401 virheen ilman kirjautumista.
robot -d outputs tests/front/tehtava9.robot

Tehtävä 10: Havaintoja

Testien tekeminen oli alkuun haastavaa ympäristön pystytyksen takia (python polut ja virtuaaliympäristö). Kun perusrakenne tuli tutuksi, testien kirjoittaminen nopeutui. API-testaus RequestsLibrarylla oli selkeämpää kuin selainpohjainen testaus.

Tässä projektissa on hyödynnetty tekoälyä Gemini teknisenä tukena.
